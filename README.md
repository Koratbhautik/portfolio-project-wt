## ✨ Features

- **Dark / Light mode toggle** — saved to localStorage
- **Responsive design** — works on mobile, tablet and desktop (Bootstrap grid + media queries)
- **Mobile navbar** — opens and closes automatically
- **Scroll animations** — smooth fade-in using IntersectionObserver
- **Active nav highlighting** — current section highlighted in navbar
- **Contact form validation** — real-time field validation with error messages
- **Typed text effect** — animated tagline in hero section
